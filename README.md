# Кадр

Локальний вебзастосунок для пошуку доступних серій і якостей на UAKINO та UAFLIX і збереження відео на Windows-комп’ютері. Сторінка працює у браузері, а завантаження виконує локальна служба. Застосунок не обходить DRM або інтерактивні перевірки сайтів.

## Запуск на іншому Windows-комп’ютері

Завантажте файл **`Kadr-Install.bat`** з [останнього релізу](https://github.com/HOKER1597/DownloadSerialsUA/releases/latest). Потрібні 64-бітна Windows та інтернет під час першого запуску. Батнік завантажує останній реліз програми з GitHub до `%LOCALAPPDATA%\DownloadSerialsUA`, перевіряє його SHA-256, а Python, бібліотеки, FFmpeg та Chromium встановлює у приватну папку програми. Готовий Python, Node.js, Git і обліковий запис GitHub не потрібні. При кожному запуску батнік перевіряє версію релізу: якщо вона нова, оновлює код; якщо та сама, запускає без повторного завантаження. Якщо GitHub тимчасово недоступний, запускається вже встановлена версія.

Перевірена тестова інсталяція займає близько **800 МіБ**. Під час першого встановлення й оновлення тимчасово потрібно більше вільного місця. Відеофайли займають місце окремо у вибраній папці.

## Запуск із вихідного коду

Потрібні Python 3.10+, Microsoft Edge, FFmpeg та ffprobe (у `PATH` або `runtime/ffmpeg`), Node.js для першого збирання інтерфейсу.

```powershell
cd frontend
npm install
npm run build
cd ..
python -m pip install -r requirements.txt
python backend/launch.py
```

Після збирання інтерфейсу наступні запуски робіть командою `python backend/launch.py` з кореня проєкту. Служба відкриє сторінку на `127.0.0.1`; браузерну вкладку можна закрити, не перериваючи завантаження. Закриття вікна служби зупиняє її, а незавершені серії потім можна повторити.

Щоб зібрати батнік після зміни інсталятора, виконайте `python tools/build_one_bat.py` у корені проєкту. GitHub Actions запускає автотести, збирає інтерфейс і публікує реліз із інсталятором, архівом та контрольною сумою після кожного оновлення гілки `main`.

## Структура й перевірка змін

Бекенд у `backend/app`: `catalog` шукає джерела й аналізує потоки, `downloads` керує чергою та FFmpeg, `storage` зберігає стан у SQLite, `system` працює з Windows та FFmpeg, `api` містить HTTP і WebSocket маршрути. Фронтенд у `frontend/src`: `features` містить пошук, каталог і завантаження; `api` викликає бекенд; `domain` описує дані; `shared` містить форматування; `styles` — стилі. Старі модулі імпорту залишені як сумісні оболонки. Деталі — у `docs/architecture.md`.

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m pytest --cov=backend/app --cov-report=term-missing
python -m ruff check backend tests/backend tools
python -m ruff format --check backend tests/backend tools
cd frontend
npm ci
npm run test:coverage
npm run format:check
npm run build
```

Автотести не звертаються до відеосайтів і не завантажують відео: зовнішні відповіді та FFmpeg замінені контрольованими тестовими даними. Для збірки архіву релізу після `npm run build` виконайте `python tools/build_release.py` у корені проєкту.

Нове джерело додавайте окремим адаптером у `backend/app/catalog/sources/`: реалізуйте пошук сторінки та визначення HLS-потоку за зразком `uakino.py` або `uaflix.py`, зареєструйте його в `registry.py`, додайте дозволені домени в `catalog/url_security.py` та тест з контрольованими HTML і плейлистом у `tests/backend/test_sources.py`.

## Використання

1. Вставте HTTPS-посилання на сторінку UAKINO або UAFLIX і натисніть «Пошук».
2. Виберіть озвучення, серії та якість. Застосунок показує повну роздільність кадру, наприклад `1920 × 800`, разом із позначкою `800p`. Розмір до завантаження позначений `≈` і є оцінкою з HLS-плейлиста.
3. За замовчуванням вибрана системна папка «Завантаження». Впишіть інший шлях — він автоматично збережеться для наступних запусків — або натисніть «Огляд» і виберіть папку у Windows. Якщо вибрано кілька серій, оберіть режим «По черзі» чи «Паралельно». Натисніть «Завантажити».
4. Під час завантаження історія показує отриманий обсяг, приблизний загальний розмір, швидкість у байтах за секунду та орієнтовний час до завершення. Після завантаження видно окремі стани збирання MP4 і перевірки. Готові MP4 з’являться у підпапці назви та сезону; часткові файли не вважаються готовими. Після успішного завантаження кількох серій у тій самій папці створюється `Сезон.m3u8` у порядку серій.
5. Історію можна шукати за назвою та фільтрувати за станом. З картки можна відкрити папку, а біля готового відео — сам файл або видалити його з диска. Застосунок просить підтвердження перед видаленням та оновлює плейлист сезону. Це остаточне видалення, без Кошика.

Завдання й історія інстальованої версії зберігаються у `%LOCALAPPDATA%\DownloadSerialsUA\data\state.sqlite3`. Субтитри не завантажуються. Якщо структура сайту або доступність потоку зміниться, адаптер може потребувати оновлення.
