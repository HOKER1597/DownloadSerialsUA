# Кадр: оновлення архітектури та автотести

Цей реліз зберігає наявний формат SQLite, HTTP/WebSocket API, часткових `.part.*.ts` і готових MP4. Інсталятор під час запуску оновлює застосунок через GitHub Releases. Його можна завантажити як окремий файл `Кадр — встановити і запустити.bat` у цьому релізі; Python, Node.js і Git на комп’ютері користувача не потрібні.

## Що змінилося

- Бекенд розділено на `catalog` (джерела UAKINO та UAFLIX, перевірка адрес, HLS), `downloads` (черга, відновлення, FFmpeg, файли), `storage` (SQLite), `system` (Windows і FFmpeg) та `api` (HTTP і WebSocket).
- Фронтенд розділено на сценарії пошуку, вибору серій і якості, завантаження та історії. Запити до бекенду, типи даних, форматування і стилі винесено в окремі модулі.
- Збережено вибір якості за шириною кадру: серії з 1920 × 960 і 1920 × 1080 належать до однієї доступної групи. Старі значення якості (`max`, `960p` тощо) залишаються підтриманими.
- Пошук FFmpeg перевіряє приватну папку інсталяції та WinGet, навіть якщо поточний `PATH` застарів.
- Відкриття файла з історії обмежено вибраною папкою завантаження. Завдання, видалене перед початком виконання, не спричиняє помилку фонового процесу.

## Перевірка

- 26 автотестів бекенду: сканування, адаптери джерел, безпека адрес, API й події, SQLite, паралельне завантаження, відновлення та файли.
- 16 автотестів фронтенду: групування якості, фільтри історії, форми, прогрес, API й основні дії користувача.
- GitHub Actions тепер запускає тести й перевірки коду перед створенням релізу. Архів містить усі нові модулі, зібраний інтерфейс і контрольну суму SHA-256.

## Для встановлення

1. Завантажте `Кадр — встановити і запустити.bat` з файлів цього релізу.
2. Запустіть його на 64-бітній Windows. Під час першого запуску потрібен інтернет; програма встановиться в `%LOCALAPPDATA%\DownloadSerialsUA`.
3. Наступні запуски цього ж батника перевірятимуть оновлення та використовуватимуть уже встановлені компоненти.

Структуру проєкту та команди для розробників описано в `README.md` і `docs/architecture.md`.
